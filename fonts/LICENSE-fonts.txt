Modified Version (Noto Sans Math subset)
----------------------------------------
math-subset.woff2 is a Modified Version of Noto Sans Math Regular, produced
by tools/build_math_font.py. It is subsetted to 2301 code points, hinting
tables are removed, and the MATH table is kept. Noto Sans Math has no
U+02D9, so that code point is copied from Noto Sans
(src/NotoSans-Regular-02D9.woff2). U+02D9 is the only code point taken
from Noto Sans; the subset is not a one-glyph font.

The CSS family name in math-embedded.css is "Hydraulics Math". The font's
internal name table was not changed and still reads "Noto Sans Math".
